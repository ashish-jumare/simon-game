# Simon Game

A browser-based memory game built with vanilla HTML, CSS, and JavaScript.

## Features

- Increasing color sequences
- Current score and level tracking
- Persistent best score using local storage
- Responsive layout for desktop and mobile
- Visual feedback for computer and player turns

## Technologies

- HTML5
- CSS3
- JavaScript

## Run Locally

1. Clone or download this project.
2. Open `index.html` in a web browser.
3. Click **Start Game**.

## How to Play

Watch the sequence of flashing colors, then click the colors in the same order. Each completed sequence increases your score and adds another color. A wrong selection ends the game.

## Project Structure

```text
index.html   Game layout
style.css    Styling and responsive design
script.js    Game logic and score management
README.MD    Project documentation
```

## Scoring

Your score increases after every completed sequence. The best score is saved in your browser and remains available after a reload.
